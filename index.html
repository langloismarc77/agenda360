🔗 Connexion Google Agenda — version 0.2

Une fois publiée sur une adresse web sécurisée et configurée dans Google Cloud, cette application peut lire ton agenda Google et tes agendas partagés accessibles, y compris leurs rendez-vous récurrents. Lecture seule : elle ne modifie rien chez Google. Les événements Google restent en mémoire temporaire de l’onglet, et ne sont pas enregistrés dans le stockage local.

Google non connecté. Les autres fonctions restent disponibles.
Période lue : de 30 jours avant aujourd’hui à 120 jours après. Les jours fériés et agendas publics auxquels tu es abonné sont également proposés. Aucun mot de passe ni jeton d’accès n’est demandé dans un formulaire.
Comment activer la connexion ?
  1. Héberger le fichier sur un site HTTPS que tu contrôles (par exemple GitHub Pages), ou l’exécuter sur http://localhost.
  2. Dans Google Cloud, créer un projet, activer Google Calendar API et configurer l'écran de consentement OAuth (ajouter ton adresse comme utilisateur de test si nécessaire).
  3. Créer un identifiant client OAuth « Application Web », avec l’adresse du site dans les « origines JavaScript autorisées » (sans chemin).
  4. Coller ici l’identifiant client finissant par .apps.googleusercontent.com, puis cliquer « Connecter Google ».

Une application Google en mode test peut nécessiter une nouvelle autorisation après une période limitée. Ton Google Agenda reste la source officielle.

Important : l'import gère les événements simples et les occurrences datées. Les répétitions complexes, annulations et exceptions ne sont pas entièrement interprétées. Vérifie les horaires importés, surtout les fuseaux horaires et changements d'heure.

Comment ça marche ?

1. Choisis les agendas à afficher.
2. Ajoute des rendez-vous ou importe un fichier .ics.
3. Consulte les chevauchements et cherche des disponibilités.

Et la synchronisation automatique ?

Google peut être connecté en lecture seule après configuration OAuth. Outlook professionnel reste en import manuel (.ics) dans cette version. Aucune connexion à Microsoft n’est activée.

Où sont mes données ?

Les rendez-vous manuels et les imports sont dans le stockage local de ce navigateur. Les données récupérées auprès de Google restent temporairement en mémoire, et sont effacées lors de la déconnexion ou de la fermeture de l’onglet. Le navigateur contacte Google directement. Évite d’importer des données professionnelles sans autorisation.
